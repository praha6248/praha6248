## Selected projects

- **[PDF Diploma Checker](https://github.com/PDF-Diploma-Checker)** – desktop app that reviews theses in PDF: typography, language, bibliography and content, with an annotated PDF and a report. Team of 7, I am the top contributor. Python, PySide6, llama.cpp.
- **[PrismaFlow](https://github.com/praha6248/PrismaFlow)** – local-first app for validating product ideas, with Windows and Linux installers and a LoRA fine-tune for UX flow audits. Python, FastAPI, React, Ollama.
- **[Robot_arm-nl](https://github.com/praha6248/Robot_arm-nl)** – robot arm controlled with natural language. A fine-tuned 362M model running in llama.cpp scores 40/40 on the benchmark, against 37/40 for Gemma 3 4B. Python, C++, PyTorch.
- **[CzytajPDF](https://github.com/praha6248/CzytajPDF)** – text extraction for Polish and English PDFs and scans with selective OCR and diacritics repair. Python, Tesseract.
- **[Robot_arm](https://github.com/praha6248/Robot_arm)** – 6-axis arm simulation with inverse kinematics, grasping and stacking. C++, OpenGL.
- **[planar-quadrotor-lqr](https://github.com/praha6248/planar-quadrotor-lqr)** – 2D quadrotor controlled by an LQR regulator. C++, Eigen, SDL2.
- **[evolutionary-path-planning](https://github.com/praha6248/evolutionary-path-planning)** – genetic algorithm for mobile robot path planning with Python bindings. C++, pybind11.
- **[fastcv](https://github.com/praha6248/fastcv)** – CUDA adaptive threshold kernel contributed to an OpenCV-style filter library. CUDA, Thrust, PyTorch.
